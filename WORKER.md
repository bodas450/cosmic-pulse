# Cosmic Pulse — посібник оператора

**Cosmic Pulse** — YouTube-канал з 3D-відео про космос (зірки, наднові, чорні діри, галактики). Відео без голосу: монтаж іде в ритм музики, склейки ставляться на такти, вибухи на дропи, світло пульсує від бочки.

Цей пакет — повна «фабрика». Ти даєш їй музику, вона віддає готові відео, Shorts, обкладинки й тексти для YouTube. **Код міняти не треба.**

```
трек у music/inbox/ ──► npm run daily ──► export/   відео 2K + обкладинка + тексти YouTube
                                        └► export/shorts/   Short 9:16 + тексти
```

Один трек дає **2 публікації**: довге відео (3–4 хв, 2560×1440) і Short (40 с, 1080×1920).

Документи:
- `WORKER.md` — цей посібник: встановлення, щоденна робота, помилки.
- `ops/MUSIC.md` — де брати музику, вимоги, 12 готових промптів.
- `ops/PLAN.md` — розклад публікацій, що міряти, правила рішень, щотижневий звіт.
- `ops/tracker.csv` — таблиця аналітики (відкривається в Excel або Google Sheets).
- `branding/CHANNEL.md` — назва, опис і ключові слова каналу.

## 1. Встановлення (один раз, ~20 хвилин)

**Комп'ютер:** Windows 10/11, macOS або Linux. Від 16 ГБ RAM, від 50 ГБ вільного місця (одне 2K-відео займає 0.3–0.7 ГБ). Відеокарта бажана: з нею рендер швидший.

| Програма | Windows | macOS |
|---|---|---|
| Node.js 20+ | nodejs.org → LTS | nodejs.org → LTS або `brew install node` |
| Python 3.10+ | python.org (увімкни **Add to PATH**) | `brew install python` |
| ffmpeg | `winget install Gyan.FFmpeg` | `brew install ffmpeg` |

Завантаж проєкт одним архівом (потрібен вхід у GitHub акаунт, що має доступ до репозиторію):
**https://github.com/bodas450/cosmic-pulse/archive/refs/heads/main.zip**
(або на сторінці репозиторію: зелена кнопка **Code → Download ZIP**). Розпакуй: вийде папка `cosmic-pulse-main` з програмою, документами й усією музикою.

Відкрий термінал **у папці `cosmic-pulse-main`** і виконай:

```bash
npm install
npx playwright install chromium
python -m pip install librosa        # на macOS/Linux: python3 -m pip install librosa
npm run doctor
```

`npm run doctor` має показати всі ✅. Якщо десь ❌, поруч написано, що зробити.

Перевір, що все працює, на швидких чернетках (~30 хв для всіх відео):
```bash
npm run make:preview
```
Результат з'явиться в `export-preview/`.

## 2. Щоденна робота

### Команди

| Команда | Що робить |
|---|---|
| `npm run daily` | бере нові треки з `music/inbox/`, призначає їм теми й рендерить усе, що ще не зроблено |
| `npm run make` | рендерить усе, що ще не зроблено (без розбору inbox) |
| `npm run status` | таблиця: які відео готові, які в роботі, скільки ідей чекає на музику |
| `npm run inbox -- --dry-run` | показує, яку тему отримає кожен трек з inbox, нічого не міняючи |
| `npm run doctor` | перевіряє, чи все встановлено |

### Рутина (~30 хвилин на день, рендер іде сам)

1. **Музика.** Поклади нові треки в `music/inbox/` (як їх отримати: `ops/MUSIC.md`). Назви файлів не важливі.
2. **Запуск.** `npm run daily`. Найкраще ввечері: рендер іде вночі. Без відеокарти це ~45–60 хв на довге відео й ~10 хв на Short.
3. **Перевірка.** Вранці переглянь нові файли в `export/` і `export/shorts/` (розділ 3).
4. **Публікація** за розкладом з `ops/PLAN.md` (розділ 4).
5. **Аналітика.** Внеси цифри опублікованих відео в `ops/tracker.csv`: через 48 годин, 7 днів і 28 днів.

**Якщо рендер перервався** (вимкнули світло, закрили термінал, перезавантаження): просто запусти ту саму команду ще раз. Він продовжить з місця зупинки, готові відео пропустить.

**Прискорення на відеокарті** (спробуй один раз; якщо з'являться помилки або чорні кадри, працюй без нього):
```bash
# Windows (PowerShell):
$env:SF_GPU="1"; npm run daily
# macOS/Linux:
SF_GPU=1 npm run daily
```

### Що з'являється в `export/`

| Файл | Що це |
|---|---|
| `The Life of a Star.mp4` | довге відео, 2K |
| `The Life of a Star.jpg` | фірмова обкладинка 1280×720 (найефектніший кадр + назва + лого) |
| `The Life of a Star.txt` | **TITLE, DESCRIPTION (з розділами по таймкодах), TAGS**, лишається скопіювати |
| `shorts/The Life of a Star (Short).mp4` | Short 9:16, 40 секунд навколо головного дропу |
| `shorts/The Life of a Star (Short).txt` | назва, опис і теги для Short |

## 3. Перевірка перед публікацією (обов'язково)

Кожне відео **переглянь повністю, зі звуком**:

- [ ] немає чорних провалів, «каші» з частинок, застиглих кадрів;
- [ ] склейки й спалахи йдуть у ритм музики;
- [ ] вибух наднової або Великий вибух (якщо є) потрапляє на найсильніший момент треку;
- [ ] звук чистий, без обривів, кінцівка плавно затихає;
- [ ] обкладинка читається навіть зменшеною (подивись її розміром із сірникову коробку).

Програма теж перевіряє кожне відео сама: тривалість, чорні кадри, гучність і **чи склейки потрапляють у біт**. Відео, яке не пройшло перевірку, **не потрапить** в `export/`, а в терміналі буде `FAILED` з причиною. Подробиці лежать у `out/<назва>/state.json`, у полі `qc`.

Якщо відео не подобається, **не публікуй його** й напиши власнику, що саме не так (з таймкодом).

## 4. Публікація на YouTube

**Довге відео:**
1. YouTube Studio → Create → Upload videos → `.mp4` з `export/`.
2. **Title** — з рядка після `TITLE` у `.txt`.
3. **Description** — весь блок після `DESCRIPTION` (розділи з таймкодами YouTube покаже як Chapters).
4. **Thumbnail** — `.jpg` з `export/`.
5. **Tags** — рядок після `TAGS`.
6. Audience: **No, it's not made for kids**.
7. **Altered or synthetic content.** Музика згенерована AI, картинка — 3D-анімація. Відповідай за поточними правилами YouTube. Якщо сумніваєшся, познач «Yes».
8. Visibility → **Schedule** на час з `ops/PLAN.md`.
9. End screen: «Subscribe» + «Best for viewer».

**Short:** завантаж `.mp4` з `export/shorts/` (YouTube сам розпізнає Short: вертикальне, до 60 с). Назву, опис і теги бери з `.txt`. Розклад — з `ops/PLAN.md`.

Після публікації внеси рядок у `ops/tracker.csv`.

## 5. Як працює черга тем

- **Каталог** (`catalog/topics.js`, список `COMPILATIONS`): 15 тем, 14 вже мають музику.
- **Банк ідей** (`catalog/ideas.js`): ще 40 тем, які чекають на музику.

Кожна тема склеює 2–3 «історії» (народження зірок, наднові, чорні діри, формування планет…). Коли ти кладеш трек у `music/inbox/`, `npm run daily` віддає його **наступній темі без музики** в такому порядку: спочатку каталог, потім банк ідей. Файл перейменовується на `music/<id-теми>.mp3`.

Хочеш, щоб трек дістався конкретній темі? Сам назви файл її id і поклади прямо в `music/` (не в inbox). Наприклад, `music/black-hole-birth.mp3`.

**Нові ідеї** додає власник або редактор у кінець `catalog/ideas.js`:
```js
  { id: 'my-new-video', title: 'My New Video', subtitle: 'short tagline', topics: ['star-birth', 'inside-black-hole'] },
```
Доступні історії: `star-birth`, `solar-system`, `sun-life-cycle`, `massive-star-death`, `galaxy-formation`, `first-stars`, `inside-black-hole`, `neutron-star`, `origin-of-gold`, `moon-formation`, `jupiter-giant`, `habitable-earth`, `red-dwarfs`, `milky-way-andromeda`, `end-of-universe`.

## 6. Правила

1. **Платні дії (кредити vidIQ, Suno тощо) — лише з погодження власника.**
2. **Музика тільки з правами** (`ops/MUSIC.md`). Один трек на одне відео.
3. **Не публікуй без повного перегляду.**
4. **Код у `src/` і `renderer/` не чіпай.** Якщо щось не працює, напиши власнику, що сталося, і додай скріншот терміналу.
5. **Бекап.** Опубліковані відео можна видалити з `out/`, щоб звільнити місце, але **`music/` і `ops/tracker.csv` не видаляй ніколи**.

## 7. Якщо щось пішло не так

| Проблема | Що робити |
|---|---|
| `npm run doctor` показує ❌ | виконай команду, написану поруч |
| `'ffmpeg' is not recognized` | перевстанови ffmpeg і відкрий новий термінал |
| `No module named librosa` | `python -m pip install librosa` |
| `browserType.launch` / `Executable doesn't exist` | `npx playwright install chromium` |
| `N ideas waiting for a track` | це нормально: просто чекають на музику |
| `no ideas left for ...` | ідеї закінчились, попроси власника додати нові в `catalog/ideas.js` |
| `QC failed: ...` | відео не пройшло автоперевірку. Не публікуй, напиши власнику |
| `beat analysis is for ..., but the video uses ...` | запусти ту саму команду ще раз, аналіз оновиться |
| Рендер дуже повільний | спробуй `SF_GPU=1` або запускай на ніч |
| Рендер зупинився | запусти ту саму команду ще раз, він продовжить |
| Закінчується місце на диску | видали з `out/` папки вже опублікованих відео |

## Що в пакеті

```
cosmic-pulse-main/
├── WORKER.md            ← цей посібник
├── ops/                 ← MUSIC.md (музика), PLAN.md (розклад і правила), tracker.csv (аналітика)
├── catalog/             ← topics.js (каталог тем), ideas.js (банк ідей)
├── music/               ← треки; inbox/ — сюди кидати нові
├── branding/            ← банер, аватарка, лого, шаблон обкладинки, опис каналу
├── renderer/  src/      ← програма (не чіпати)
├── export/              ← готові відео, обкладинки й тексти (з'являється після рендеру)
└── out/                 ← робочі файли рендеру
```
